# Arduino-DC-Motor-Control
A simple Arduino project that controls 4 DC motors using two L293D motor driver in Tinkercad.
## Description
This project uses an Arduino Uno and two L293D motor drivers to control four DC motors. The motors:
- Move forward for 30 seconds.
- Move backward for 1 minute.
- Turn right and left for 1 minute.

## Technologies Used
- Tinkercad
- Arduino Uno
- L293D Motor Driver
- C++ (Arduino IDE)

## Circuit Connections
- Arduino 5V → Powers the L293D logic.
- Battery → Powers the DC motors.
- Common GND → Shared by the Arduino, battery, and both L293D drivers.
